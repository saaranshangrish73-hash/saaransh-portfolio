## ⚡ How to Deploy on Vercel (1-Minute Setup)

1. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New..." > "Project"**.
3. Select the **`saaransh-portfolio`** repository.
4. Click **"Deploy"** (Vercel will automatically detect `vercel.json` & `index.html`).
5. Your portfolio is now live with a free custom SSL domain (`https://saaransh-portfolio.vercel.app`)!
